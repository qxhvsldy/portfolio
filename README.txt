【使用方法】
解压后直接双击 index.html 即可（推荐 Chrome / Edge）。
全站离线可用，无需联网、无需本地服务器。

【交互速查】
· 所有图片（证书/展板/图纸）点击可放大灯箱查看
· 作品卡片点击打开故事页，ESC 关闭
· 短片卡片：点两侧卡片切换焦点，点中间卡片播放
· 3D 实验室：拖拽旋转、滚轮缩放、双击复位
· 支持 prefers-reduced-motion 无障碍降级

【技术说明】
· 极光：原生 WebGL shader，无外部库
· 3D：three.js r128（本地内置）+ GLB 模型 base64 内嵌，file:// 直开可用
· 全部资源为相对路径本地文件，无任何 CDN 外链
· 短片为 720p H.264 压缩版（原始 4K 素材未打包以控制体积）
